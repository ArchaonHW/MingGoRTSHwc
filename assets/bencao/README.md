# 本草條目編輯說明

## 文獻定位

遊戲中的《本草拾遺》是供戰役查閱的文獻冊頁；條目參照明代藥學家李時珍（1518–1593）所撰《本草綱目》。原書五十二卷、十六部，萬曆二十四年（1596）於南京刊行。遊戲內的八類是便於查閱的改編分類，並非原書部目的逐項轉錄。

## 遊戲分類

分類順序固定，需與 `Campaign/Narrative/Bencao.h` 的 `BencaoCategory` 及本草頁目錄一致：

| JSON `category` | 遊戲目錄 |
| --- | --- |
| `shancao` | 山草類 |
| `xicao` | 隰草類 |
| `ducao` | 毒草類 |
| `manshui` | 蔓水類 |
| `gucai` | 穀菜類 |
| `jinshi` | 金石類 |
| `chongshou` | 蟲獸類 |
| `renbu` | 人部拾遺 |

## 條目格式

每種藥材各用一個 `potato.bencao/1` JSON 檔案：

- `id`：穩定、唯一的英文識別碼；檔名與識別碼一致。
- `category`、`name`：使用上表中的分類代碼與繁體中文正名。
- `aliases`、`origin`：可選的釋名與集解資料。
- `nature`、`indications`：保留歷史文獻語境的性味歸經與主治摘要。
- `source`：指出《本草綱目》的部、卷與條目，例如 `本草綱目·草部卷十二·人參`。
- `unlock`、`lang`：依既有 schema 填入有效解鎖條件與語言標記。

條目描述用於歷史考據與遊戲敘事，不代表現代醫療建議。避免把傳統記載寫成已驗證的現代療效，也不添加現實用藥劑量或治療指引。`批註` 是遊戲執行期間產生的記錄，不得寫入靜態條目。
